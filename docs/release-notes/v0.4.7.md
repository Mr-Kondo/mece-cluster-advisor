## 変更

- `docs/dimensionality-reduction.md` に「入れるかの判断」を追加した。次元削減を opt-in の `--reduce` として入れるかを検討し、入れないと決めた(#39)。利得が出たモデル(multilingual-e5-small)に UMAP を足しても、既定の ruri-v3-310m の生の埋め込みと同じか下回った(livedoor `title` で 0.383 と 0.436、`lead` で 0.450 と 0.492、MASSIVE ja で 0.623 と 0.621)。
- 「入れ直す条件」を、上の判断に合わせて改めた。

`SKILL.md` と `scripts/` は変わっていない。スキルの動作は同じである。

## 確かめていないこと

- 次元削減が、境界の項目や重複しやすいグループの指摘の質を上げるか(ARI は測ったが、指摘の質は測っていない)。
- ruri-v3-310m の livedoor の値と e5-small の値は、別のスクリプトの出力である。サンプルの中身までは同じと確かめていない。
