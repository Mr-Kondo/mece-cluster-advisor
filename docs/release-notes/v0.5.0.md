# v0.5.0

- `install.py` と `scripts/test_install.py` を削除した。配置・更新・削除は `npx skills add` / `update` / `remove` を使う(README と docs/usage.md を参照)。
- CI は単体テストだけを Linux と Windows で動かす。real-model ワークフローはリポジトリ内のスクリプトを直接動かす。
- 取得したモデルと依存の削除は、`--purge` の代わりに docs/usage.md の手動手順を使う。
- 破壊的変更: `uv run install.py` は使えなくなった。旧インストーラの配置からの移行は docs/usage.md の「skills CLIでの登録・更新・削除」を参照する。
