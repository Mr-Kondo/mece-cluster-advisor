## 修正

- `install.py` が、Git の作業ツリーでは追跡しているファイルだけをコピーするようにした。これまでは名前の並び(`EXCLUDE`)で除いていたので、並びに無い名前の未追跡ファイル(`.env`、`secrets.txt` など)が作業ツリーにあると、インストール先へ複製された。修正前は、ダミーの 9 ファイルがすべて複製された。修正後は 0 件で、追跡しているファイルの内容は修正前と同じだった(#27)。
- `--device` に、利用できないデバイスを明示したとき(例: CUDA が無い環境で `--device cuda`)、PyTorch の長い例外ではなく `error: デバイス 'cuda' は利用できません。--device auto か cpu を指定する。` で終わるようにした(#33)。

zip の展開先など、Git の管理外から `install.py` を実行したときは、今までどおり名前の並びで除いてコピーする。この Release の zip は追跡しているファイルだけなので、影響を受けない。

## 確認したこと

- この Mac(Apple Silicon)で、実モデル(ruri-v3-310m)を使い、`--device mps`・`--device auto`(`mps` を選ぶ)・`--device cpu` で 17 件を 3 グループに分けた。3 つとも、分かれ方と silhouette(平均 0.0778、項目ごとの差は 0)が一致した(#26)。
- CI に、未追跡の私的ファイルがコピーされないこと、追跡しているファイルが欠けないこと、Git の管理外(`git archive` の展開先)から入れられることの検査を足した(#27)。

## 確かめていないこと

- Linux・Windows での実モデルの実行(#25)。
- CUDA・Intel XPU・DirectML・NPU での実モデルの実行。実機が手元に無い(#26)。
