## 重要: インストール先に、私的な指示ファイルが複製されていないか確認してください

v0.4.1 以前の `install.py` は、リポジトリ直下に `CLAUDE.local.md` や `AGENTS.local.md`(Git の対象外にしている私的な指示ファイル)があると、インストール先(`~/.claude/skills/mece-cluster-advisor`、`~/.agents/skills/mece-cluster-advisor`)へそのまま複製していました。v0.4.2 で、`*.local.md` を除外しました(#23)。

- 手元のリポジトリから v0.4.1 以前の `install.py` を実行したことがあれば、上の 2 か所に `*.local.md` が無いか確認してください。あれば削除してください。そこに秘密(トークンなど)を書いていた場合は、無効にして再発行してください。
- この Release の zip から入れる場合は、影響を受けません(追跡されているファイルだけが入ります)。

## 修正

- `install.py` が `*.local.md` をコピーしないようにした。CI の「コピーされないことの検査」に、`CLAUDE.local.md` と `AGENTS.local.md` のダミーを足した(#23)。

`scripts/` と `SKILL.md` は変わっていない。スキルの動作は同じである。

## 更新のしかた

- リポジトリから: `git pull` して、リポジトリ直下で `uv run install.py`。
- この Release から: `mece-cluster-advisor.zip` を展開し(`mece-cluster-advisor.sha256` で確認)、展開先で `uv run install.py`。

## 確認したこと

- 修正前の `install.py` は `CLAUDE.local.md` をコピーし、修正後はコピーしないことを、ダミーのコピーで確かめた。
- 単体テストと `install.py` の検査(コピーされないことの検査を含む)を、GitHub Actions の Linux と Windows で通す(この PR の CI)。

## 確かめていないこと

- `*.local.md` 以外の、手元に置かれる私的なファイル(名前を並べた除外に無いもの)。除外は名前の並びで、リポジトリが追跡しているファイルだけをコピーする方式ではない。
